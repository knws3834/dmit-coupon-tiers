# DMIT 優惠碼：Pro／EB／T1 各線路折扣碼適用範圍、結帳 Validate Code 步驟與洛杉磯香港東京套餐價格對照

會搜這個詞的人，多半已經在 DMIT 的購物車裡看過一輪價格，只是還沒按下結帳。DMIT 不是那種每逢大促就全場五折的商家，它的碼一直不多，而且幾乎每個碼都被綁死在三個條件上：哪個機房、哪條線路、哪種付款週期。所以真正有用的資訊不是一張越長越好的碼表，而是「這串碼配哪個方案才會生效」。

先把最容易踩的坑講清楚：**同一串碼，配對方案可能省兩成，配錯方案驗證直接失敗，連錯誤訊息都只會淡淡地告訴你這碼無效。**

## DMIT 的優惠碼生態，先把期待值調對

DMIT 成立於 2017 年，機房在洛杉磯、香港、東京三地，產品按回國路由分成 Premium（Pro）、Eyeball（EB）、Tier 1（T1）三條線。它的定價策略更像是在賣稀缺資源，而不是在打價格戰：CN2 GIA 這種線路的成本擺在那裡，官方與其說不想給折扣，不如說不願意為了銷量把線路賣爛。

結果就是兩種優惠形式並存：

- **付款週期自帶的折扣。** 選半年付或年付，價格本來就比月付低；部分系列官方直接寫明年付有折扣，不需要輸入任何碼。DMIT 官方在部分洛杉磯 Pro 方案上就標註過「年付享折扣，無需優惠碼」。
- **循環折扣碼。** 這類碼一旦生效，會跟著你的續費週期一直折下去，不是只折首期。DMIT 大部分公開碼屬於這一類，這也是它比一次性首購碼值錢的地方。

2025 年聖誕檔期 DMIT 做過一次比較大的動作：符合條件的洛杉磯產品給最高 10% 的餘額返還，另外最高 20% 的持續折扣，返還的金額按 12 個月平均、每月結算一次。這種「折扣 + 分期返還餘額」的組合是 DMIT 少見的慷慨時刻。要提醒的是，那是當時的活動條件，不是現在的常態。

## 循環折扣、返現與 Validate Code 的實際操作

DMIT 用的是 WHMCS 結帳系統，驗證流程跟大部分同類商家一樣，但順序有講究：

1. 先選機房與方案，按 Continue 進到訂單設定頁，選付款週期、root 密碼、作業系統。
2. 附加項目（額外 IPv4、記憶體、硬碟）確認後按 Continue，進到購物車總覽。
3. 在購物車頁面找到 **Apply Promo Code** 欄位，貼上碼後按 **Validate Code**。
4. 系統會即時回報結果，成功的話下方總價立刻變成折後金額；失敗就是這個碼跟你的方案、週期不匹配。
5. 確認金額無誤再按 Checkout。

這裡有個容易被忽略的細節：**折扣碼要在購物車階段驗證，不是付款頁才填。** 有些人一路按到確認付款畫面才想起來手上有碼，回頭還得重來一次。

至於「循環」的意思，是指這個碼對續費同樣生效。你第一年打八折，第二年續費還是八折，除非 DMIT 政策改變或你更換方案。返現的部分則不同，它是把錢退到你的帳戶餘額，通常按月分批入帳，不能立刻當現金折抵。

## 挑碼之前先挑線路：Pro、EB、T1 到底差在哪

選錯線路再怎麼疊碼都白搭。同樣 1 核 2G 的機器，Pro 和 T1 的月費可以差好幾倍，差別全在回國路由上。

| 線路 | 路由特徵 | 適合誰 | 價位 |
| --- | --- | --- | --- |
| Premium（Pro） | 三網回程 CN2 GIA，去程電信 CN2 GIA、聯通 9929／CUG VIP、移動 CMIN2 | 對中國大陸訪問品質有硬要求，不接受晚高峰掉速 | 最高 |
| Eyeball（EB） | 三網回程 CMIN2，去程電信在 9929／58807 之間負載均衡 | 預算優先，但希望大陸住宅用戶的體驗比普通線路好 | 中等 |
| Tier 1（T1） | 純國際 BGP，無中國專項優化 | 純國際流量、備份、CI/CD、中轉落地 | 最低 |

一句話判斷：大陸體感優先選 Pro，預算優先選 EB，只跑國際業務選 T1。三條線都有「流量用完不停機、降到指定速率繼續跑」的機制，T1 的超量限速通常是 100Mbps 到 200Mbps，Pro 與 EB 則多在 4Mbps 到 10Mbps 之間——這個差距在實際使用裡比帳面數字有感得多。

## 下單前該留意的限制

庫存是最大的變數。洛杉磯與東京的熱門配置經常處在售完狀態，補貨時間不固定，社群裡甚至有「美西優化線路溢價翻倍」的說法。你在文章裡看到的價格，可能在你下單時那個方案已經沒貨。

其他幾件容易忽略的事：

- 註冊時建議關掉代理工具、用真實資訊填寫，DMIT 對明顯異常的註冊 IP 或偽造資訊有風控，可能直接觸發自動退款。
- 姓與名要用拼音填寫，不要輸入中文。
- 預設用 SSH 金鑰登入，第一次連線前要先上傳或產生公鑰。
- 選購時可加購「IP Guarantee+」，作用是保證分配到的 IP 在敏感地區可用；不買的話，買到不可用 IP 得自己想辦法。
- 支付方式支援支付寶、PayPal、信用卡，部分情況也接受加密貨幣。PayPal 若自動換算成人民幣，記得手動切回美元，匯率差會吃掉一部分折扣。
- 洛杉磯 AS3 平台官方曾標註仍處於持續優化階段，磁碟效能與 SLA 可能低於成熟平台。要跑重要業務的話，先測試再上線。

## 常見問題

**碼驗證失敗是怎麼回事？**
九成是條件不符。DMIT 的碼通常限制機房、產品線與付款週期三項，月付用季付的碼、WEE 用 STARTER 的碼、洛杉磯的碼拿去買香港，都會直接失敗。先把付款週期調成碼要求的檔位再試。

**同一個訂單可以疊兩串碼嗎？**
不行，購物車的 promo code 欄位一次只吃一個。

**年付折扣和優惠碼能同時用嗎？**
